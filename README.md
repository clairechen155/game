# 卡牌对对碰

这是一个可直接托管到 GitHub Pages 的单文件网页游戏。卡牌图片已嵌入 `index.html`，无需上传素材目录或运行构建命令。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 将本文件夹中的 `index.html` 和 `README.md` 上传到仓库根目录并提交。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
5. 等待 GitHub Pages 发布完成后，复制页面显示的 `https://用户名.github.io/仓库名/` 地址分享。

游戏余额、局数和盒柜记录保存在每位玩家自己的浏览器中，不会跨设备同步。
